# Security

MIGOps can perform privileged GPU reconfiguration, so security issues should be handled carefully.

Do not publish exploit details, credentials, private host information, or sensitive infrastructure data in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use it for security-sensitive reports. Otherwise, open a minimal issue requesting a private contact method without including the sensitive technical details.

When reporting a non-sensitive safety bug, include the MIGOps version, GPU model, NVIDIA driver version, command used, and sanitized output.
